# Events Hub

Free directory of event suppliers in Ejisu and Juaben Municipalities (Ashanti, Ghana). A charity project of MCA Desk.

- `site/` — the website (installable web app). Plain HTML, CSS and JavaScript; no build step.
- `supabase/` — database setup scripts, run in order in the Supabase SQL Editor.

The website talks to Supabase with the publishable key in `site/config.js`, which only allows what the database's security rules allow.
